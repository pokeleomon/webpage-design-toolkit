## 1. Linear (`linear.app`)

- File: https://getdesign.md/linear.app/design-md
- Character: ultra-minimal, precise, purple accent.
- Best for: dashboards, dev tools, dense data UI (pairs with the
  minimalist path — no reference image needed).

## 2. Vercel (`vercel`)

- File: https://getdesign.md/vercel/design-md
- Character: black-and-white precision, Geist type.
- Best for: marketing pages and docs where restraint and sharp type
  carry the design.

## 3. Stripe (`stripe`)

- File: https://getdesign.md/stripe/design-md
- Character: signature gradients, weight-300 elegance.
- Best for: fintech/marketing pages that need polish without noise.

## 4. Spotify (`spotify`)

- File: https://getdesign.md/spotify/design-md
- Character: vibrant green on dark, bold type, album-art-driven.
- Best for: media/consumer pages and dark playful worlds (e.g. game-adjacent).
